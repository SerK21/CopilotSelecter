Copilot Default Model

Copilot Premium で毎回モデルを選ぶ手間を省きます。Chrome と Edge（制限あり）で動作します。

基本設定

対応プリセット

  • 自動 — 考える時間の長さを自動で決める
  • クイック応答 — すぐに回答する
  • Think Deeper — 長く考える（トップレベル）
  • GPT 5.6 Think Deeper — GPT サブメニュー
  • GPT 5.6 Quick response — GPT サブメニュー
  • GPT 5.5 Quick Response — GPT サブメニュー
  • Sonnet — Claude サブメニュー
  • Opus — Claude サブメニュー

Microsoft Edge について

Edge 135 以降では copilot.microsoft.com へのコンテンツスクリプト注入が ブラウザ側でブロックされる場合があります（Chrome では動作）。Edge で使う場合は Chrome を使うか、Microsoft の制限解除を待つ必要があります。
