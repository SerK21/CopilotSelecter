CopilotSelecter — Edge / Chrome への入れ方
==========================================

Windows（会社の Edge 152 公式ビルド向け）
  1. CopilotSelecter-Setup.exe を実行する
  2. edge://extensions でデベロッパーモードをオン
  3. 「パッケージ化されていない拡張機能を読み込む」で
     表示されたフォルダを選ぶ
  4. https://m365.cloud.microsoft/chat を通常タブで開く

  copilot.microsoft.com と Edge サイドバー Copilot は
  Edge が保護しているため拡張は動きません。

ZIP だけ使う場合
  1. copilotselecter-chrome.zip を解凍する
  2. Edge なら edge://extensions、Chrome なら chrome://extensions
  3. デベロッパーモードをオン
  4. 解凍フォルダ（manifest.json がある場所）を読み込む
