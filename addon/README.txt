CopilotSelecter — Chrome への入れ方
====================================

いちばん楽な方法（Windows）
  1. CopilotSelecter-Setup.exe をダウンロードして実行する
  2. Chrome の「デベロッパーモード」をオンにする
  3. 「パッケージ化されていない拡張機能を読み込む」で、
     セットアップが表示したフォルダを選ぶ
     （パスはクリップボードにコピー済み）

ZIP だけ使う場合
  1. copilotselecter-chrome.zip を解凍する
  2. Chrome で chrome://extensions を開く
  3. デベロッパーモードをオン
  4. 「パッケージ化されていない拡張機能を読み込む」
  5. 解凍したフォルダ（中に manifest.json がある方）を選ぶ

※ Google Chrome はセキュリティ上、.exe から拡張機能を黙って
  インストールすることを禁止しています。最後の 2 クリックは必須です。
